Everything you need for seamless digital asset management in one unified platform.

Multi-File Uploads

Drag and drop multiple files simultaneously with client-side validation, size calculation, and isolated per-user directory storage.

Public Shareable Links

Generate one-click cryptographically secure UUID tokens. Share files instantly with external partners with view and download counts.

In-Browser Previews

Instant rich previewing for images, code files, JSON, markdown, and PDFs right inside the web interface without extra plugins.

Stateless JWT Security

Robust authentication with BCrypt hashing, authorization headers, CORS protection, and Spring Security 6 filter chains.

Storage Quota Tracker

Live calculation of storage quota, byte usage progress meters, favorite starred filters, and instant keyword searching.

Zero-Config Persistence

Embedded H2 Database with Spring Data JPA entities, ready to launch out of the box with optional zero-code switch to PostgreSQL or MySQL.

Clean Fullstack Project Structure

Strict separation of concerns between responsive web clients and robust Spring Boot microservices.

Architecture Highlights

  • ✔ Frontend: Pure modern HTML5, CSS3 with dark mode, and vanilla ES6+ JavaScript. Features automatic offline sandbox fallback.
  • ✔ Controllers: AuthController for token flows and FileController for uploads, downloads, previewing, and public sharing.
  • ✔ Services & Repositories: FileStorageService managing disk directories and quotas; JPA repositories with derived queries.
  • ✔ Security: Stateless JWT filter chain, BCrypt hashing, and cross-origin CORS configuration.
